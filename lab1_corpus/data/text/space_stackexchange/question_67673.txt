What is the difference between BCRS and ICRS?
The IAU 2000-2012 Resolutions on Reference Systems states that
For all practical applications, unless otherwise stated, the BCRS [Barycentric Celestial Reference System] is assumed to be oriented according to the ICRS [International Celestial Reference System] axes.
From my understanding, the choice of axes, by means of setting the coordinates of fiducial celestial objects, defines a reference frame as opposed to a reference system. So my first conclusion was that the ICRS was a BCRF.
But that cannot be the case, because the resolutions and other documents such as this infopage at IERS also define separately a ICRF, International Celestial Reference Frame.
So now I'm completely confused.
At some point I was thinking that the difference might have been in the definition of the time coordinate in the two systems, but that doesn't seem to be the case.
So I would like to ask the following set of interrelated questions:
What is the difference between BCRS and ICRS?
What is the difference between "setting the axes" of a reference system, vs "setting the coordinates of fiducial celestial objects" (which should define a reference frame)?
Is the time coordinate precisely defined for BCRS and for ICRS?
Are there references that explain these matters in detail?

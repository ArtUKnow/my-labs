Modeling Magnetometer in Extended Kalman Filter
I added a magnetometer to my CubeSat simulation but I am confused on how i should handle my measurement noise covariance. The outputs of my magnetometer are my unit vectors for reference mag field and body mag field (with error). My innovation or residual is the difference between measured unit vector and predict body frame mag field. My confusion is that both of these, including my measurment matrix, contain unit vectors, but my noise covariance is in nT. You see, after converting my reference mag field to the body frame I add some sigma to it and then normalize my vectors to produce the measurements.
How should I go about handling the measurement noise covariance. Furthermore, when I test my innovation and its covariance it always passes because the measurement noise covariance is a lot larger than H or P?
% Example Pseudocode
%% Generating measurements, refMeasI is coming from World Magnetic Model.
Cb2i = quatToDCM(truth.qb2i); % converting truth quaternion to DCM
sigma = 100; % nano-tesla (nT)
magI = refMeasI; % reference magnetic field in Inertial Frame (nT)
magB = Cb2i'*refMeasI + sigma*randn(3,1) % measured field in body frame nT
% EKF Update
% inputs:
% state: struct containing current state estimate
% sigma: noise from magnetometer in nT
% P: Covariance [6 x 6]
% X: error state vector [6x1] three component attitude error & gyro bias
`Cb2i_hat = quatToDCM(state.qb2i); Current quaternion estimate
magB = magB/norm(magB); normalizing magnetometer measurement in body frame`
Cb2i_hat = quatToDCM(state.qb2i); Current quaternion estimate
magB = magB/norm(magB); normalizing magnetometer measurement in body frame
magI = magI/norm(magI); normalizing reference field in inertial frame
pred = Cb2i_hat' * magI; % predicted magnetic field in body frame
R = eye(3) * sigma^2; % measurement noise covariance; eye(3) is identity
H = zeros(3, 6); % initializing measurement matrix
H(:,1:3) = skew(pred); % measurement matrix = skew symmetric matrix of pred
S = (H*P*H.'+R); % inovation covariance
K = P*H.'/ S; % kalman gain
delZ = magB - pred; % innovation
accepted = delZ*delZ'./ S < chi_squared_threshold % boolean for gating
if (accepted)
X = X + K*delZ; % Update State
P = (eye(length(H) - K*H))*P; Update Covariance
end

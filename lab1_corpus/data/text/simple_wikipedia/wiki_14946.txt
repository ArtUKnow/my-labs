Windows 95
Windows 95 is an operating system created by Microsoft. Microsoft sent it to computer makers on July 14, 1995, and stores began selling it on August 24, 1995. It was the first operating system in the Windows 9x family, replacing Windows 3.1. Although Windows 95 is thought of as an operating system by itself, it works on top of MS-DOS. You can think of it as a visual version of MS-DOS. This means Windows 95 can run both MS-DOS programs and Windows ones, but programs made just for Windows 95 will not work in MS-DOS.
Windows 95 introduced a new graphical user interface (GUI). It brought the Windows Explorer file manager, file shortcuts on the desktop, and a taskbar with a notification area and the Start menu. This was the first Windows operating system to use the Start menu. Since then, the Start menu has been used in almost all Windows operating systems, except for the "tablet-design" Start screen in Windows 8.
Windows 95 also added many technical improvements. It introduced Plug-and-Play driver setup to help users add new hardware easily. It was Microsoft's first operating system to support long file names up to 255 characters (letters, numbers, or symbols), plus the file extension. Before that, file names could only be eight characters long. Before that, file names could only be eight characters long, plus a file extension. It was also the first Windows operating system with built-in ways to connect to the Internet, and the first to fully support CD-ROMs (though Windows 3.x could also access CD-ROMs with MSCDEX).
Microsoft spent a lot of money advertising Windows 95 before its release. Windows 95 was a major success and is considered one of the most important products in personal computing history.
Windows 95 remained popular until three years later, when Microsoft introduced Windows 98. Microsoft ended mainstream support for Windows 95 on December 31, 2000, and ended extended support on December 31, 2001. At that time, Windows for Workgroups 3.11 and Windows NT 3.1 were not yet released.
Microsoft wanted to make two new operating systems. The first was a high-end system for business users, code-named Cairo. The second was a simpler system for home users, code-named "Chicago." Chicago was designed to replace Windows 3.1 by using new 32-bit technology.
Cairo was planned as Microsoft's next main system based on Windows NT, featuring a new user interface and file system. However, Microsoft never released Cairo. Instead, parts of the Cairo project were used in Windows NT 4.0 in July 1996. Its new file system was left out, but it later became WinFS.
When Windows 3.1 was released, IBM started selling OS/2 2.0. Microsoft realized it needed an updated version of Windows. This new system needed to support 32-bit programs and run multiple tasks at the same time. It also needed to work on cheaper, less powerful computers, which Windows NT could not do.
At first, the "Chicago" team did not know how the final product would be sold. They thought about making two separate products: MS-DOS 7 (a text-based system based on Windows for Workgroups 3.11) and a fully combined graphical Windows system.
Beta
Before Microsoft released Windows 95, people in the United States and United Kingdom could join the Windows 95 Preview Program. For US$19.95 or £19.95, people received several 3.5-inch floppy disks to install Windows 95. They could use the disks to upgrade from Windows 3.1 or install it as a new system. They also got a free trial of The Microsoft Network (MSN), an online service that Microsoft launched alongside Windows 95. At this time, Microsoft shared online documents and guides about Chicago. This included a special guide for reporters that explained the main features of the new system.
These preview versions stopped working in November 1995. After that, users had to buy the final version of Windows 95.
Release and sell
Microsoft got $720 million on release day.

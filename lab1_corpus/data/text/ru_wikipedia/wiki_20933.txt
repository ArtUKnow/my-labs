Среднее степенное
Среднее степенное (среднее обобщённое, среднее по Гёльдеру, среднее по Минковскому) — разновидность среднего значения, обобщающее ряд самых известных средних; для набора положительных вещественных чисел x_1, \ldots, x_n среднее степени d определяется как:
A_d(x_1, \ldots, x_n) = \sqrt[d]{\frac{\sum\limits_{i=1}^n x^d_i}n} .
По принципу непрерывности относительно показателя d доопределяются следующие величины:
A_0(x_1, \ldots, x_n) = \lim_{d\to 0} A_d(x_1, \ldots, x_n) = \sqrt [n]{\prod_{i=1}^n x_i};
A_{+\infty}(x_1, \ldots, x_n) = \lim_{d\to +\infty} A_d(x_1, \ldots, x_n) = \max\{ x_1, \ldots, x_n \};
A_{-\infty}(x_1, \ldots, x_n) = \lim_{d\to -\infty} A_d(x_1, \ldots, x_n) = \min\{ x_1, \ldots, x_n \}.
Обобщает среднее арифиметическое ( A_1 ), среднее геометрическое ( A_0 ), среднее гармоническое ( A_{-1} ) — так называемые архимедовы средние, а также среднее квадратичное ( A_2 ), среднее кубическое ( A_3 ), среднее биквадратическое ( A_4 ). В свою очередь, само среднее степенное является частным случаем колмогоровского среднего при выборе степенной функции в качестве опорной.
Наряду с понятием «среднее степенное», используют также среднее степенное взвешенное для величин с весами.
Неравенство о средних утверждает, что для любых d_1 > d_2 имеет место
A_{d_1}(x_1, \ldots, x_n) \geqslant A_{d_2}(x_1, \ldots, x_n) ,
причём равенство достигается только в случае равенства всех аргументов x_1 = \ldots = x_n . Результат следует из того, частная производная A_d(x_1, \ldots, x_n) по d неотрицательна и обращается в нуль только при x_1 = \ldots = x_n (например, в связи с неравенством Йенсена), и далее может быть применена формула конечных приращений. Неравенство о среднем арифметическом, геометрическом и гармоническом является его частным случаем.

Transit photometry: Precisely calculating Single/Multiple Event Statistics with Box-Least-Squares selected periods?
I'm working on a python light curve feature extraction pipeline, currently implementing multiple transit detection. For the model subtraction part, instead of fully relying on Astropy's Box-Least-Squares (BLS) best-fitting candidate and recursively removing the period, I'm opting for a different approach:
First, use BLS to detrend and get the periodogram
Use scipy.find_peaks over the periodogram to find local power maxima
Calculating the power of every signal and selecting the ones with the highest values
Computing the Single Event Statistic (SES) and Multiple Event Statistic (MES) values of each candidate
Filtering by only the ones which MES >= 7.1σ (Which was the same used in Kepler according to Nasa's official paper)

This makes me think that the signal-to-noise ratio calculation isn't fully wrong, but rather just slightly miscalculated.
The pipeline computes SES/MES using a time-domain, duration-matched box filter (which is more like an approximation to Kepler Transiting Planet Search (TPS) without adaptive wavelet whitening). At each cadence, it estimates the mean flux deficit within a window equal to the candidate transit duration. The local baseline and noise are estimated from out-of-transit samples using the median and Gaussian-equivalent MAD, with corrections for incomplete window coverage.
For each valid cadence, the matched-filter components are
$$
D_i = \sigma_i^{-2}, \qquad N_i = \delta_i D_i,
$$
so the single-event statistic is
$$
\mathrm{SES}_i = \frac{N_i}{\sqrt{D_i}} = \frac{\delta_i}{\sigma_i}.
$$
Predicted transit centers are generated from the BLS period and epoch and matched to the nearest valid cadence. Their components are then combined coherently:
$$
\mathrm{MES} = \frac{\sum_i N_i}{\sqrt{\sum_i D_i}}.
$$
max_ses is, in this case, the largest positive cadence-level SES, while max_mes keeps the BLS period and duration fixed but searches small epoch offsets within approximately half a transit duration.
The entire MES/SES computation algorithm is available at https://github.com/rachzy/ltp-features/blob/main/src/sesmes.py

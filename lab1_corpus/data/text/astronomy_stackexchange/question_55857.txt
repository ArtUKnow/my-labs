Current sources for astronomical equation coefficients
For a project I needed to implement some of the code to calculate the position of the sun and moon. To do this I'm using Meeus. Everything is working but in doing so I've started to wonder about the currently accepted coefficient values for the various polynomials.
First a concrete example. Per Chapter 22 the Earth/Sun Mean Anomaly is found using a polynomial of the Julian Ephemeris Century (jce)
357.52772 + 35999.050340jce - 0.0001603jce^2 - (1.0/300000)jce^3
But then Chapter 25 uses coefficients of:
357.52911, 35999.05029, -0.00011537
And Chapter 47 says:
357.5291092, 35999.0502909, -0.0001536, 1.0/24490000
Each of these is footnoted saying where Meeus got the coefficients from. Ch22 says Astronomical Almanac for 1984 page S26. Ch25 says the source is a disk of planetary tables. Ch47 says Chapront's lunar theory ELP-2000.
I could give other examples such as the Moon's Argument of Latitude, or it's Mean Longitude, but I think this gives the idea. There are quite a few of these polynomials.
But Meeus' 2nd edition is from 1998. I rather suspect that someone has worked up new values for these. Where would I find them? I'd think someone (NOAA?) would have a publicly available list of the "best" values. Possibly they're calculated from the DE-nnn tables available from JPL?
I do want to be clear on one thing. I don't need anything better than the values in Meeus. This is just academic interest. There are people who need highly accurate and precise values. Where do they get them?

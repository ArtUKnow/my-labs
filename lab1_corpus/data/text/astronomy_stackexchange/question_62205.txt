How to get the brightest stars in astropy?
I'm using astropy and I want to get a list of the brightest stars.
My current approach is
from astroquery.simbad import Simbad
simbad = Simbad()
simbad.add_votable_fields("V")
simbad.query_catalog("Gaia", criteria="V<0")
simbad.query_objects("*", wildcard=True, criteria="V<0")
simbad.query_criteria("V<0")
The first query returns nothing; apparently Gaia doesn't have bright stars. The second query returns many copies of each star. The third query works, but is deprecated. This seems like it should be easy and I've read lots of documentation, but I think I'm off in the weeds. Is Simbad even the right thing to use?

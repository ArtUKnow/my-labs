How to approach writing software to find planetary alignments
This isn't a request for calculations or formulas — I have those, but I'd like to sense check how one might structure a program to calculate when an alignment would occur between two or more planets on the ecliptic or a certain angle being formed between them on that plane.
I have formulas that can calculate the position of the planet for a given time. It seems reasonable that the formulas could be reversed to be able to find the time when that planet was at a certain position (or a set of possible times). That's two formulas — relatively straightforward.
But for calculating when multiple planets form a certain angle to each other, the only way I can think to go about it (other than iteratively) is to come up with what would be a very elaborate simultaneous equation based on the formulas for the individual planets involved, to mathematically equate the angle and figure out what the time value would be when that happened.
Even if I could do that, it would then involve at least one formula for each combination of planets — and that's just for two-planet combinations. Is that what is typically done?
I'm prepared to do the work if that's the right approach to take, but is it? Or is there a smarter way to structure a program to avoid having to figure out the formulas for every desired combination and write a separate routine for each?

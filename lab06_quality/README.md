# Качество поиска

Код: `metrics.cpp, rank.cpp`. Результаты: `results/`. Команды выполняются из корня проекта.

```sh
./build/ir metrics lab06_quality/results/qrels.tsv lab06_quality/results/stem_run.tsv 5
```

Полный пересчёт запускается только указанной командой; готовые результаты сохраняются. Общие инструкции — в корневом README.

# Корпус

Код: `corpus.cpp`. Результаты: `results/`. Команды выполняются из корня проекта.

```sh
./build/ir prepare
./build/ir corpus-stats lab01_corpus/data/provenance/scoap3.tsv lab01_corpus/data/text/scoap3 /tmp/corpus_stats.json
```

Полный пересчёт запускается только указанной командой; готовые результаты сохраняются. Общие инструкции — в корневом README.

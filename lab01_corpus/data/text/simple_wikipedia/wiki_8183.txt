This PC
This PC is seen on the Microsoft Windows computers. This PC allows the user to access the local drives, such as the local disk, also known as the C: Drive. The user can also access external drives. Examples of an external drive are a floppy disk drive (A: Drive) and the CD Drive (D:). This PC also lets the user access Documents and other files.
Whenever any external drive is attached to the computer, the user can directly access that drive from the This PC menu. "This PC" gives an overview about different types of drives present in the computer. The This PC folder is a gateway to all the data stored on the computer, attached devices, and the network -- as well as a shortcut to most of your system information.

Accurate angluar diameter calculations of the Moon and the Sun
I'm looking for two accurate calculations for the perceived angular diameter of the Moon and the Sun, for a given observer (of known latitude and longitude) at a given moment in time (UTC).
I currently have the following for J.L. Lawrence's "Celestial Calculations: A Gentle Introduction to Computational Astronomy":
function getSolarAngularDiameter(datetime: Date): number {
// Get the true anomaly:
const ν = getSolarTrueAnomaly(datetime)
// Get the F orbital paramater which applies corrections
// due to the Sun's orbital eccentricity:
const F = getFOrbitalParameter(ν, 0.016708)
return 0.533128 * F
}
and
function getLunarAngularDiameter(datetime: Date): number {
// Get the true anomaly:
const ν = getLunarTrueAnomaly(datetime)
// Get the F orbital paramater which applies corrections
// due to the Moon's orbital eccentricity:
const F = getFOrbitalParameter(ν, 0.0549)
return 0.5181 * F
}
These are to sufficient accuracy for most scenarios, except during a solar or lunar eclipse. (They usually give around 0.53 - 0.55 degrees of diameter for the Moon and the Sun, e.g., 31' arcminutes).
This means, when I go to calculate the magnitude for either a Total, Hybrid or Annular solar eclipse, for example, my magnitude values are either off by a few degrees for Total, or greater than 1 for an Annular eclipse, meaning that the Moon is "bigger" than the Sun in it's angular diameter.
This is, of course, wrong.
They also can't be used to calculate the duration of an eclipse and other such features, to great accuracy.
I have been trying to reference more accurate calculations of these values, e.,g., from Meeus, but to no avail.
Would anyone either know of a more accurate routine, or know of any literature I could reference that could give me more accurate angular diameter models...

Are evolution calculations predictable for a star in an n-body system?
In a binary system, stellar evolution calculations are relatively easy, as one can accurately calculate mass transfers and chemical composition changes in one of the two stars, thereby affecting one of the stars' evolution compared to an individual star. We can see the changes in a star's evolution in a binary system because of these predictable effects. However, are these same calculations accurately predictable for a tertiary system and any n-body system?
I know most systems we observe contain stars that are too far apart from each other to affect a star's evolution. But I want to ask about an imaginary scenario: What if all the stars in an n-body system are close together; how can we predict the changes in their evolution? Is it possible?

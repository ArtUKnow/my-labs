How to correctly create a coadded detection image from multi-band data
Using Panstarrs (PS) data, I've made cutouts centered on my target galaxy for all the objects in my sample. For each galaxy, there is a set of five image cutouts from PS in all the five bands: g,r,i,z,y (examples of cutouts in attached png files).
My goal is to do global aperture photometry on each image. To start, my original method was to create a source mask based only on the g-band PS image cutout for each galaxy. Then apply this source mask to all the other bands. In this case it's simple because all PS images are on the same pixel-grid and share a common WCS, so resampling is not required.
But the issue with creating a source mask from the g band and applying it to all the other bands (r,i,z,y), was that anything that was faint in g but bright in the other bands, was not 'detected' in the source mask. So each g-band image would be very well masked, but the r,i,z,y images with the same mask would have a larger number of unmasked objects.
So the solution I was looking into was, instead of creating a source mask from the g band only, I thought I would Coadd the g+r+I images (or some combination) and create a source mask from that coadded detection image. its only purpose would then be for me to make a source mask which I could then apply to the original single band grizy images to then do photometry.
For now, I'm trying to figure out what the 'correct' way to create such a detection image is. I was trying to do this with SWarp. Configuration file attached below.
When I did the combination with the config file as below using COMBINE_TYPE: WEIGHTED, it gave me the detection image attached (titled g+r+I WEIGHTED COMBINE_TYPE). It looks fine (? I dont know what checks I can make to see its correct). But based on some research, I read a better way of combining multi-band images to create a detection image was to use CHI COMBINE_TYPE (either of the options listed in SWarp). I tried that and got an image with weird looking artefacts (titled g+r+I CHI COMBINE-TYPE). Im not really sure what's going on under the hood, or the correct way to be making this detection image and dont want to assume just because the weighted one visually looks fine, that it is. Good thing is that im not measuring flux of the detection image, it's just to create a source mask which I can then apply to the single band images from which I will measure flux. But I was curious. is there a recommended prescription people use to create such an image? it does not necessarily have to be using Swarp. Or if swarp is fine, what are the standard input configuration parameters that should be run for this type of task.
Any advice would be appreciated.
thank you

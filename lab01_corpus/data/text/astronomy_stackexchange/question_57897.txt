Here the controller seeks to eliminate or minimize the difference between a given signal (this can be either a constant signal of the desired physical nature or time-varying) and the desired state of the control object-system measured using a sensor.

This is how this system works. The wave front of electromagnetic waves from the object of observation passes through outer space and is distorted (small cosmic bodies, dust, etc. can introduce aberrations). It is then reflected from a mirror with a customizable spatial configuration and hits a “light splitter.” One branch goes to the image recording and storage device. The other branch goes to the wavefront sensor, after which the signal enters the control system. An internal "wavefront corrector" adjusts the spatial configuration of the mirror so that...
And this is where my question begins: The fact is that in such a system we cannot set the reference signal in the form “the controlled output signal of the control object must be equal to 5 V (roughly speaking).” We also cannot set the desired image, because... such an adaptive optics system would not make sense, and besides, we do not know in advance what the object of observation looks like (a high-quality image of, for example, a star cluster is the result of the system’s operation). The term "wavefront corrector" contains the necessary instructions. But what kind of correction are we talking about? How do you know if the wavefront is corrected correctly? Are the properties of the wavefront sensor used for this? Or are integral indicators used (for example, the Strehl number or others)? Or does the system not use a reference signal, as in classical control systems, but maximizes some indicators of the quality of the adaptive optical system and the image obtained with its help?
Generally speaking, how does an adaptive optics system know that the image on the left is bad and the image on the right is good? How does this rate?

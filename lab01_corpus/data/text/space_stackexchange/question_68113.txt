Calculating azimuth and elevation of a ground station in satellite coordinate frame
I have a satellite 'Sat' and Ground Station 'GS'. I'm defining elevation and azimuth with respect to satellite boresight which is always pointing at nadir. More specifically, elevation is the angle of the Sat-GS vectors between boresight and the cross-track direction, while azimuth is the angle between boresight and along-track. I.e., zero degrees in elevation and azimuth would mean the target being direction under the satellite's boresight. My idea is to use transform the relative position vectors into the satellite coordinate frames using the nadir-pointing quarternion attitudes at each timestep, then used those to derive the angles.
Here's what a snippet I've tried on GMAT:
GMAT Sat.Attitude = NadirPointing;
% Body alignment vector is [1 0 0]. Body Constraint Vector is [0 0 1].
% Position Vectors in ECEF
GMAT 'RelX' RelX = Sat.EarthFixed.X - GS.EarthFixed.X;
GMAT 'RelY' RelY = Sat.EarthFixed.Y - GS.EarthFixed.Y;
GMAT 'RelZ' RelZ = Sat.EarthFixed.Z - GS.EarthFixed.Z;
% Quarternions of Nadir-pointing satellite
GMAT 'q0' q0 = Sat.Q4 %scalar term;
GMAT 'q1' q1 = Sat.Q1;
GMAT 'q2' q2 = Sat.Q2;
GMAT 'q3' q3 = Sat.Q3;
% Rotation Matrix to satellite coordinate frame
GMAT 'R11' R11 = 1 - 2 * (q2^2 + q3^2);
GMAT 'R12' R12 = 2 * (q1*q2 - q0*q3);
GMAT 'R13' R13 = 2 * (q1*q3 + q0*q2);
GMAT 'R21' R21 = 2 * (q1*q2 + q0*q3);
GMAT 'R22' R22 = 1 - 2 * (q1^2 + q3^2);
GMAT 'R23' R23 = 2 * (q2*q3 - q0*q1);
GMAT 'R31' R31 = 2 * (q1*q3 - q0*q2);
GMAT 'R32' R32 = 2 * (q2*q3 + q0*q1);
GMAT 'R33' R33 = 1 - 2 * (q1^2 + q2^2);
% Apply Rotation Matrix to ECEF position vectors
GMAT 'RelX_trans' RelX_trans = R11 * RelX + R12 * RelY + R13 * RelZ %Nadir axis;
GMAT 'RelY_trans' RelY_trans = R21 * RelX + R22 * RelY + R23 * RelZ %Cross-track axis;
GMAT 'RelZ_trans' RelZ_trans = R31 * RelX + R32 * RelY + R33 * RelZ %Along-track axis;
% Elevation: Angle in the Nadir/Cross-track plane
GMAT 'cross_track_vector' cross_track_vector = RelY_trans / sqrt(RelX_trans^2 + RelY_trans^2 + RelZ_trans^2); % Normalized cross-track vector
GMAT 'boresight_vector' boresight_vector = RelX_trans / sqrt(RelX_trans^2 + RelY_trans^2 + RelZ_trans^2); % Normalized boresight vector
GMAT 'Elevation' Elevation = Rad2Deg(acos(boresight_vector * cross_track_vector));
% Azimuth: Angle in the Nadir/Along-track plane using dot product
GMAT 'along_track vector' along_track_vector = RelZ_trans / sqrt(RelX_trans^2 + RelY_trans^2 + RelZ_trans^2); % Normalized along-track vector
GMAT 'Azimuth' Azimuth = Rad2Deg(acos(boresight_vector * along_track_vector));
% Horizon masking
If GrazingAngle >= 0
Report ReportFile Azimuth Elevation
EndIf
The results seemed impossible. I'm getting elevation and azimuth >90 degrees, implying the ground station being above the satellite. I suspect either the rotation matrix is wrong or the angle calculation has issues. Any help would be much appreciated thanks!

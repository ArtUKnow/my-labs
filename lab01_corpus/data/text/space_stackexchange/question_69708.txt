Why do some NORAD TLEs have an 8-char eccentricity field?
Recently some TLEs from NORAD have become incompatible with sgp4 propagators. Particularly, in this page I can find the following couple of TLEs:
1 38337U 12025A 25217.58590528 .00000496 00000+0 12011-3 0 9999
2 38337 98.2026 157.6217 0001506 86.4377 86.4686 14.57109748703070
1 38338U 12025B 25217.97092249 .00000419 00000+0 94351-4 0 9993
2 38338 98.3094 171.7797 00062896 20.2744 339.8706 14.61476211705291
Checking them with a Python module sgp4, I get the following result, which implies that the first TLE is valid, while the second isn't.

>>> from sgp4.io import twoline2rv
>>> s='1 38337U 12025A 25217.58590528 .00000496 00000+0 12011-3 0 9999'

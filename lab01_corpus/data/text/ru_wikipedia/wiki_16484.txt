Сочетание
В комбинаторике сочетанием из n по k называется набор из k элементов, выбранных из n -элементного множества, в котором не учитывается порядок элементов.
Соответственно, сочетания, отличающиеся только порядком следования элементов (но не составом), считаются одинаковыми — этим сочетания отличаются от размещений. Так, например, наборы букв латинского алфавита ABC и ACB представляют собой разные размещения, но одно и то же сочетание.
В общем случае число всех возможных k -элементных подмножеств n -элементного множества стоит на пересечении k -й диагонали и n -й строки треугольника Паскаля .
Число сочетаний
Число сочетаний из n по k равно биномиальному коэффициенту
n\choose k} = C_n^k = \frac{n!}{k!\left(n-k\right)!}.
При фиксированном n производящей функцией последовательности чисел сочетаний \tbinom{n}{0} , \tbinom{n}{1} , \tbinom{n}{2} , … является
\sum_{k=0}^n \binom{n}{k} x^k = (1+x)^n.
Двумерной производящей функцией чисел сочетаний является
\sum_{n=0}^{\infty} \sum_{k=0}^n \binom{n}{k} x^k y^n = \sum_{n=0}^{\infty} (1+x)^n y^n = \frac{1}{1-y-xy}.
Свойства сочетаний
Симметрия
C_n^k = C_n^{n-k}.
Выбор k элементов из n равносилен выбору n-k элементов, которые не войдут в подмножество. Следует непосредственно из формулы, так как при замене k на n-k числитель не меняется, а два множителя знаменателя меняются местами.
Рекуррентное соотношение (правило Паскаля)
C_n^k = C_{n-1}^{k-1} + C_{n-1}^k.
Это правило лежит в основе построения треугольника Паскаля. Каждый элемент равен сумме двух элементов, стоящих над ним. Из n элементов можно выбрать k либо включив фиксированный элемент (тогда остаётся выбрать k-1 из оставшихся n-1 ), либо не включив его (тогда выбираем k из n-1 ).
Сумма всех сочетаний
C_n^0 + C_n^1 + C_n^2 + \cdots + C_n^n = 2^n.
Вытекает из бинома Ньютона при x = 1 : (1+1)^n = 2^n . Суммарное число всех подмножеств n -элементного множества, включая пустое, равно 2^n .
Знакочередующаяся сумма
C_n^0 - C_n^1 + C_n^2 - C_n^3 + \cdots + (-1)^n C_n^n = 0.
Вытекает из бинома Ньютона при x = -1 : (1-1)^n = 0 . Следовательно, число подмножеств с чётным числом элементов равно числу подмножеств с нечётным числом элементов и каждое из этих чисел равно 2^{n-1} .
Свойство поглощения
k \cdot C_n^k = n \cdot C_{n-1}^{k-1},
или, эквивалентно, C_n^k = \dfrac{n}{k}\, C_{n-1}^{k-1} . Проверяется прямым раскрытием через факториалы и удобно для упрощения выражений, содержащих произведения числа сочетаний на множитель.
Сумма квадратов
\left(C_n^0\right)^2 + \left(C_n^1\right)^2 + \left(C_n^2\right)^2 + \cdots + \left(C_n^n\right)^2 = C_{2n}^n.
Частный случай тождества Вандермонда. Число способов выбрать n элементов из 2n можно подсчитать, разбив множество на две равные половины и перебрав все возможные распределения выбора между ними: \sum_{k=0}^{n} C_n^k \cdot C_n^{n-k} = C_{2n}^n , а по свойству симметрии C_n^{n-k} = C_n^k .
Тождество «хоккейной клюшки»
C_k^k + C_{k+1}^k + C_{k+2}^k + \cdots + C_n^k = C_{n+1}^{k+1}.
Название связано с геометрической интерпретацией в треугольнике Паскаля. Диагональный столбец слагаемых и результат образуют фигуру, напоминающую хоккейную клюшку. Доказывается индукцией по n с использованием правила Паскаля.
Максимальное значение
Биномиальные коэффициенты C_n^k при фиксированном n возрастают с ростом k до середины и убывают после неё (в силу свойства симметрии):
если n чётно, единственный максимум достигается при k = n/2 ;
если n нечётно, максимум достигается при k = (n-1)/2 и k = (n+1)/2 , причём оба значения равны.
Сочетания с повторениями
Сочетанием с повторениями из n по k называется такой k -элементный набор из n -элементного множества, в котором каждый элемент может участвовать несколько раз, но в котором порядок не учитывается (мультимножество). В частности, число монотонных неубывающих функций из множества \{1,2,\dots,k\} в множество \{1,2,\dots,n\} равно числу сочетаний с повторениями из n по k .
Число сочетаний с повторениями из n по k равно:
\overline{C^k_n}=C^k_{(n)}=\left(\!\!\binom{n}{k}\!\!\right)=\binom{n+k-1}{n-1} = \binom{n+k-1}{k} = (-1)^{k} \binom{-n}{k} = \frac{(n+k-1)!}{k!\cdot (n-1)!}.
При фиксированном n производящая функция чисел сочетаний с повторениями из n по k равна
\sum_{k=0}^{\infty}\left[(-1)^k {-n\choose k}\right] x^k = (1-x)^{-n}.
Двумерной производящей функцией чисел сочетаний с повторениями является
\sum_{n=0}^{\infty} \sum_{k=0}^{\infty} (-1)^k {-n\choose k} x^k y^n = \sum_{n=0}^{\infty} (1-x)^{-n} y^n = \frac{1-x}{1-x-y}.

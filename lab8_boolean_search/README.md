# Лабораторная 8: булев поиск на C++

Основная реализация: `native/index.cpp`. Python используется только для HTTP-оболочки. Рабочий корпус — 32 491 статья, индекс бинарный.

```sh
make -j2
python3 scripts/package_index.py --extract
printf 'dark matter\n' | ./build/ir search lab1_corpus/data/native_index --json --limit 50
python3 scripts/web_native.py --port 8000
```

Поддерживаются И (`&&` или пробел), ИЛИ (`||`), НЕ (`!`), скобки. Веб-выдача содержит 50 результатов, заголовки, ссылки и переход к следующей странице. Формат индекса: `native/INDEX_FORMAT.md`. Полные команды и ограничения описаны в корневом README. Старые Python-файлы являются справочной реализацией и не участвуют в основном поиске. Отчёт будет обновлён отдельно по просьбе студента.

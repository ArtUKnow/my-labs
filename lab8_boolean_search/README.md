# Лабораторная 8 · Булев поиск

Задание взято из [списка лабораторных курса МАИ](https://github.com/toshunster/MAI-IR#оценивание-лабораторных-работ). Здесь №8 — булев поиск. Старый файл «Задания-2021.pdf» нумерует темы иначе.

Поиск работает по индексу лабораторной 7 и по всем 30 000 документам. Поддерживаются пробел и `&&` (И), `||` (ИЛИ), `!` (НЕ), круглые и квадратные скобки. Приоритет: НЕ → И → ИЛИ. Например:

```text
(марс || mars) (ракета || rocket)
(спутник || satellite) !луна
((asteroid || астероид) (orbit || орбита)) || (спутник !луна)
```

## Запуск

Из корня репозитория, Python 3.8+:

```sh
printf '(марс || mars) (ракета || rocket)\n' | python3 lab8_boolean_search/cli.py
python3 lab8_boolean_search/web.py --port 8000
```

Веб-страница откроется по адресу `http://127.0.0.1:8000/`. На ней есть форма, заголовки, ссылки на оригиналы, краткие фрагменты и переход к следующим 50 результатам. Сервис локальный; для доступа с другого компьютера можно задать `--host`.

CLI читает по одному запросу в строке UTF-8. По умолчанию выводит первые 50 результатов. Опции: `--offset 50`, `--limit 50`, `--all`, `--jsonl`. Ошибки синтаксиса выводятся явно.

```sh
python3 lab8_boolean_search/test_lab8.py
python3 lab8_boolean_search/benchmark.py
```

Отчёт и план проверки — [report.md](report.md) и [report.pdf](report.pdf); результаты тестов и измерений — в `results/`.

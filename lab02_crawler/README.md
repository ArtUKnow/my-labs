# Поисковый робот

Код: `crawler.cpp`. Параметры: `config.yaml`. SQL: `sql/`.

```sh
./build/ir crawl lab02_crawler/config.yaml
```

Программа принимает один YAML-файл. Сохраняет исходники в SQLite, восстанавливает очередь, отправляет условные запросы и обновляет изменившиеся документы. Робот последовательный: `workers: 1`; это сохраняет простой код. Готовая полная база уже опубликована, повторно скачивать её для поиска не нужно. Тесты проверяют настоящий HTTP: 200, 304 и изменение содержимого.

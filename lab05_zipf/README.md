# Закон Ципфа

Код: `zipf.cpp`. Результаты: `results/`. Команды выполняются из корня проекта.

```sh
./build/ir zipf lab01_corpus/data/native_documents.tsv /tmp/zipf.json /tmp/zipf.svg
```

Полный пересчёт запускается только указанной командой; готовые результаты сохраняются. Общие инструкции — в корневом README.

# Лабораторные работы по курсу «Информационный поиск» (МАИ)

Основной корпус: **32 494 полнотекстовых научных статей по физике высоких
энергий**, каждая содержит не менее **3 000 английских слов в основном тексте**.
Статьи взяты из открытого репозитория [SCOAP³](https://repo.scoap3.org/)
нескольких научных журналов. Поиск и статистика лабораторных 3, 5, 7, 8
работают с этим корпусом. Ранние коллекции Википедии, arXiv и Stack Exchange
сохранены как архивные учебные примеры; они не входят в основной корпус и текущую оценку лабораторных 4 и 6.

Лабы используют Python 3 и стандартную библиотеку; импорт PDF дополнительно
использует `pdftotext`. Структуры данных для индекса сделаны самостоятельно.

Состояние: минимум 30 000 статей достигнут. Цель 50 000 ещё не достигнута; соответствующий тест намеренно сообщает об этом. Остальные проверки корпуса проверяют минимум задания, DOI, длину, лицензию, размеры и SHA-256 каждого файла. Исходное задание требует C/C++; текущая реализация на Python этому требованию не соответствует.

## Структура

```
lab1_corpus/             импорт научных статей, статистика и данные корпуса
lab2_crawler/            поисковый робот (yaml-конфиг, sqlite, возобновление, переобкачка)
lab3_tokenizer/          токенизация и замер скорости
lab4_stemmer/            стеммер Портера (ru/en), лемматизатор, сравнение качества поиска
lab5_zipf/               закон Ципфа и Мандельброта, график svg
lab6_search_quality/     метрики P, R, MAP, DCG, NDCG, ERR и сравнение систем
lab7_boolean_index/      булев инвертированный индекс (блочная сборка + слияние, бинарный формат)
lab8_boolean_search/     булев поиск: И/ИЛИ/НЕ, скобки, CLI и веб-страница
run_all.sh               запуск всех автотестов (или пересборка результатов: ./run_all.sh build)
```

## Запуск

Требуется только `python3` (3.9+). Для повторного скачивания корпуса нужен
доступ к сети.

```
gzip -dk lab1_corpus/data/index/postings.bin.gz  # распаковать готовый индекс после клонирования
./run_all.sh            # прогон тестовых планов всех лаб, отчёты в labXX/results/test_report.txt
./run_all.sh build      # пересчитать все результаты по корпусу
```

Лаба 2 по умолчанию использует `config.yaml` и возобновляемый сборщик SCOAP³, записывающий тот же корпус, который анализируют лабы 1 и 3–8. Для увеличения цели измените `corpus.target`. Прямой запуск: `python3 lab2_crawler/crawler.py --scoap3 --collect-only --target 50000 --min-words 3000`. Старый HTML-робот с SQLite и переобкачкой сохранён как дополнительный пример: `config_html_example.yaml`.

## Происхождение корпуса

Основной корпус лежит в `lab1_corpus/data/text/scoap3` в сжатом формате
`.txt.gz`. `lab1_corpus/data/primary_text/scoap3` — ссылка на эту коллекцию.
Каждый файл содержит заголовок и очищенный основной текст статьи. Таблица
`lab1_corpus/data/provenance/scoap3.tsv` содержит идентификатор, DOI, журнал,
год, ссылку на запись, URL исходного XML или PDF, лицензию, число слов и SHA-256
распакованного текста. Допускаются только CC BY, полный XML с разделом `body`
или полный PDF с выделенными разделами «Introduction» и «References», и как
минимум 3 000 английских слов между ними. Метаданные и текст проверяются
отдельно; короткие статьи, исправления и файлы только с метаданными
отбрасываются. Для извлечения текста из PDF нужна утилита `pdftotext`.

Импорт воспроизводится командой:

```sh
python3 lab2_crawler/crawler.py --scoap3 --target 50000 --min-words 3000
```

Скрипт сохраняет промежуточные результаты и продолжает после перезапуска.
Публичный API SCOAP³ возвращает не более 10 записей за запрос, поэтому полный
сбор занимает длительное время. Тексты распространяются по лицензиям CC BY;
при использовании статьи указывайте авторов и DOI на странице оригинала.
Исходные XML/PDF после извлечения не сохраняются: `raw_bytes` — сумма их размеров при скачивании (для ранней части восстановлена через HTTP HEAD), а `stored_bytes` — размер локальных gzip-файлов.
Сбор распределён между Mac и вспомогательным сервером; статьи объединены по ID и DOI.

Полный состав `lab1_corpus/data/text`:

| Коллекция | Документов | Содержимое |
|---|---:|---|
| `ru_wikipedia` | 10 000 | русские статьи; 40 исходных HTML-страниц |
| `simple_wikipedia` | 5 000 | статьи на простом английском; 20 исходных HTML-страниц |
| `scoap3` | 32 494 | полные научные статьи, не менее 3 000 слов |
| `arxiv_astronomy` | 5 000 | заголовки и аннотации астрономических работ |
| `space_stackexchange` | 5 000 | вопросы о космических полётах |
| `astronomy_stackexchange` | 5 000 | вопросы об астрономии |

Аннотация или вопрос в дополнительных коллекциях — отдельный документ, но
**не полный текст статьи**. Они не используются для подтверждения объёма
основного корпуса. В `lab1_corpus/data/provenance/*.tsv` есть данные об их
происхождении.
Для Stack Exchange взяты только вопросы с явно указанной в API лицензией
CC BY-SA 4.0; очищенный текст является преобразованной версией страницы.
При распространении соблюдайте
[условия атрибуции Википедии](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use),
[условия arXiv для метаданных](https://info.arxiv.org/help/oa/index.html) и
[лицензии Stack Exchange](https://stackoverflow.com/help/licensing).

Для воспроизведения импорта скачайте первые 128 МиБ каждого дампа (команды
ниже выполняются из корня репозитория), затем запустите импортёр. Снимки
фиксированы на 01.11.2026; частичных архивов в репозитории нет.

```sh
curl -fL -r 0-134217727 -o /tmp/ruwiki-20261101.bz2 https://dumps.wikimedia.org/ruwiki/20261101/ruwiki-20261101-pages-articles-multistream1.xml-p1p224167.bz2
curl -fL -r 0-134217727 -o /tmp/simplewiki-20261101.bz2 https://dumps.wikimedia.org/simplewiki/20261101/simplewiki-20261101-pages-articles-multistream.xml.bz2
python3 lab1_corpus/import_wikimedia_dump.py /tmp/ruwiki-20261101.bz2 ru_wikipedia 9960
python3 lab1_corpus/import_wikimedia_dump.py /tmp/simplewiki-20261101.bz2 simple_wikipedia 4980
python3 lab1_corpus/import_arxiv.py 5000
python3 lab1_corpus/import_stackexchange.py space 5000
python3 lab1_corpus/import_stackexchange.py astronomy 5000
```

SHA-256 скачанных частей: `7e4a51fb5b8e9449472973f04d8d7961f697471e89a4fbe0350463639597e1c2`
(русская), `f0e269b79d78f39d050b876e08dc4992ba2873377280dc733211c0d6cd696708`
(Simple English). Импортёр Wikimedia пропускает перенаправления, пустые статьи и
заголовки уже имеющихся HTML-примеров. Данные API arXiv и Stack Exchange
собраны 26.11.2026; повторный запуск позже может выбрать другие записи.
`corpus_stats.py`, токенизатор, анализ Ципфа и булев индекс работают по
основному корпусу SCOAP³. Лабы 4 и 6 выполняют поиск по **всем 32 494 статьям**, сравнивая raw, stem и lemma. Оценка использует 44 запроса на поиск известной статьи: по четыре из каждого журнала, выбор детерминирован через SHA-256 DOI, запрос — первые восемь слов заголовка. DOI задаёт единственную статью-цель. Файлы запросов, qrels и доказательства происхождения — `lab1_corpus/data/queries/scoap3/`. Старые запросы и Wikipedia baseline перенесены в `queries/legacy/` и не участвуют в текущем запуске.

Это автоматически сформированный тест поиска конкретной статьи; заголовки присутствуют в документах. Он не заменяет независимую ручную разметку тематической релевантности. P@5 здесь не может превышать 0,2: для каждого запроса только одна статья-цель. R@5 показывает долю найденных целей, а NDCG@5 — насколько высоко они стоят.

Пакетный поиск сохраняет только постинги слов запросов, но просматривает каждый документ; нормализация, TF и ранжирование совпадают с `SimpleSearch`, что проверено отдельным тестом. Словарь лемматизатора также строится по всем документам. Лаба 6 использует ту же выдачу, что и лаба 4; её кеш проверяется по корпусу, токенам, запросам и коду.

Текущие NDCG@5: raw **0,6710**, stem **0,5713**, lemma **0,6063**. В этом эксперименте raw лучше; универсального преимущества нормализации результат не показывает.

Токены и индекс можно пересоздать командой
`./run_all.sh build`.

Для демонстрации основного индекса: `printf 'dark matter\n' |
python3 lab7_boolean_index/index_reader.py`. В результатах есть документы
SCOAP³ из нескольких журналов.

# Мои лабораторные по информационному поиску

Ганяк Александр Олегович · М8О-408Б-23.

**Все программы на C++. Python не нужен.** Корпус, готовый индекс и результаты сохранены. Полный пересчёт при обычном запуске не выполняется.

## Начать работу

Откройте терминал в папке проекта:

```sh
./run.sh build
./run.sh test
./run.sh search dark matter
./run.sh web
```

Веб-поиск: [http://127.0.0.1:8000](http://127.0.0.1:8000). Для нескольких запросов: `./run.sh search`, затем вводить по одному запросу на строку. Выход: Ctrl+D; остановка сервера: Ctrl+C.

После нового клонирования один раз распакуйте готовый индекс:

```sh
./run.sh restore-index
```

Нужны компилятор C++17, make, zlib, libcurl, SQLite. На macOS используются системные библиотеки Command Line Tools. На Ubuntu: `g++ make zlib1g-dev libcurl4-openssl-dev libsqlite3-dev libssl-dev`. Для повторного извлечения PDF может понадобиться `pdftotext`; готовые тексты и индекс уже приложены.

## Где что находится

| Папка | Что делает |
|---|---|
| `lab01_corpus` | Таблица документов, пути, статистика корпуса, данные |
| `lab02_crawler` | Скачивание, база исходников, возобновление, проверка изменений |
| `lab03_tokenizer` | Разбиение UTF-8 текста на токены, статистика |
| `lab04_stemmer` | Стемминг, ограниченная лемматизация, правила окончаний |
| `lab05_zipf` | Частоты слов и график Ципфа |
| `lab06_quality` | Метрики, TF-IDF и BM25, запросы и результаты оценки |
| `lab07_index` | Блочное построение бинарного индекса и его формат |
| `lab08_search` | HTTP-сервер, форма поиска, страницы результатов |
| `common` | Общие структуры, UTF-8, заголовочные файлы |
| `main.cpp` | Выбор команды |
| `validation` | Сохранённые результаты проверок |

В каждой папке `README.md` содержит короткую команду запуска. Код разделён на небольшие функции; общие таблицы Unicode и правила окончаний вынесены в заголовочные файлы. Комментарии из исходников убраны. Объяснения для защиты и новые отчёты подготовим отдельно.

## Данные и готовые результаты

Основной корпус — **32 491 уникальная статья**, минимум 3 000 английских слов основного текста. Источники — 11 журналов по физике высоких энергий, доставка через [SCOAP³](https://repo.scoap3.org/). Таблица происхождения содержит DOI, журнал, URL, лицензию и SHA-256. Полная база исходников содержит 32 491 XML/PDF и 32 491 HTML-страницу; ресурсы не выдаются за дополнительные статьи.

Готовый индекс: `lab01_corpus/data/native_index/`. Архив для восстановления: `lab07_index/results/native_index.tar.gz`. Все окончательные файлы индекса бинарные. Формат: [lab07_index/FORMAT.md](lab07_index/FORMAT.md).

Результаты лежат в `results` каждой лабораторной. Они относятся к полному корпусу; ограничение старого учебного примера на 60 документов исключено. Статистика: **220 126 009 токенов**. Нормализация, индекс, поиск, метрики, TF-IDF и BM25 выполняются на C++ без STL. Для файлов, сети, сжатия и базы применяются C/POSIX, libcurl, zlib и SQLite. Готовые контейнеры и алгоритмы STL в поисковом ядре не используются.

Оценка качества содержит 44 воспроизводимых запроса на поиск конкретной статьи по части заголовка. Это автоматическая проверка идентификации статьи, а не независимая ручная тематическая разметка. Лемматизация ограничена правилами и исключениями; полноценного морфологического словаря нет. Для базовой работы используется стемминг.

Полная база исходников опубликована отдельно из-за размера: [GitHub Release](https://github.com/ArtUKnow/my-labs/releases/tag/cpp-labs-v1). При необходимости: `./run.sh download-raw`. Сначала проверяются SHA-256 частей, затем восстанавливается SQLite. Для обычного поиска этот архив скачивать не нужно.

## Что проверяется быстро

`./run.sh test` компилирует программу и запускает маленькие тестовые примеры: UTF-8, стемминг, метрики по ручным расчётам, несколько блоков индекса, булевы операции, URL/HTML, SQLite и сохранение исходников. Корпус и большой индекс при этом не пересчитываются.

Обновить только локальные пути после перемещения папки: `./run.sh prepare`. Содержимое документов и индекс эта команда не меняет.

Ориентир — [текущие задания курса](https://github.com/toshunster/MAI-IR). Обязательный минимум 30 000 статей выполнен; личная цель 50 000 не достигнута. Уникальность корпуса среди одногруппников и итоговую оценку подтверждает преподаватель. Новые отчёты отложены по просьбе студента; старые отчёты не используются как описание текущей C++-версии.

# Булев индекс

Код: `index.cpp`. Результаты: `results/`. Команды выполняются из корня проекта.

```sh
./build/ir build lab01_corpus/data/native_documents.tsv /tmp/new_index stem 500000
```

Полный пересчёт запускается только указанной командой; готовые результаты сохраняются. Общие инструкции — в корневом README.
